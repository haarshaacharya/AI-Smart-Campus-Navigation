# AI Smart Campus Navigation System

An AI-based accessible campus navigation prototype using face detection, voice recognition, spoken directions, and Arduino LED indicators.

## Features

- Face detection using OpenCV
- Automatic voice welcome
- Voice-based destination recognition
- Spoken navigation instructions
- Arduino LED indication
- STOP / EXIT button

## Technologies Used

- Python
- OpenCV
- SpeechRecognition
- SoundDevice
- Windows Speech API
- Arduino UNO

## Hardware

- Arduino UNO
- Laptop with camera and microphone
- LEDs and resistors
- Breadboard and jumper wires
- Physical campus map

## Project Status

Software prototype developed. Physical LED navigation map integration is in progress.

## How It Works

1. The camera detects a visitor's face.
2. The system welcomes the visitor.
3. The visitor asks for a destination.
4. The system recognizes the destination.
5. The laptop announces the direction.
6. Arduino controls the corresponding LED indicator.
